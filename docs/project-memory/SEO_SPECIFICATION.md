# SEO Specification

The active SEO requirements are documented in `SEO_REQUIREMENTS.md`.

## Build Acceptance Criteria

- Every public route exports metadata or uses a shared metadata helper.
- Dynamic routes have canonical URLs and Open Graph images.
- Missing artwork falls back to a branded default image.
- Sitemap includes indexable static and dynamic pages.
- Robots rules are explicit for launch.
- Structured data is added for organization, website/search, articles, and public events where data is reliable.
