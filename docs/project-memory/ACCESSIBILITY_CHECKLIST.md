# Accessibility Checklist

- Color contrast meets WCAG AA.
- Keyboard navigation works for nav, player, filters, cards, forms, and modals.
- Focus states are visible and tokenized.
- Icon-only buttons have accessible labels.
- Player state is announced with text, not color alone.
- Forms have labels, errors, and helper text connected to inputs.
- Modals trap focus and return focus on close.
- Images include useful alt text or are marked decorative.
- Motion respects `prefers-reduced-motion`.
- Pages use semantic landmarks and one H1.
- Search results and schedule updates are understandable to screen readers.
