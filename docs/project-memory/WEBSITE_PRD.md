# Website PRD

## Summary

The redesigned Voices Radio website should be a mobile-first public platform for listening live, discovering shows and artists, browsing schedule and events, and converting users into studio bookings, ticket buyers, members/supporters, and community participants.

## Success Criteria

- Live listening is available globally and is never buried.
- Users can discover shows and artists through browse, genre, alphabet, and search patterns.
- Schedule is clear, timezone-safe, and resilient to empty/error states.
- Commercial CTAs are visible but secondary to listening and discovery.
- Pages are responsive, accessible, SEO-ready, and instrumented.

## Launch Scope

- Homepage
- Listen live experience
- Schedule
- Shows index/detail
- Artists index/detail
- Events index/detail
- Studio booking
- Membership/support if provider is confirmed
- News/articles if content ownership is confirmed
- About/contact/legal pages
- Search

## Non-Goals For Launch

- Full user account system
- Saved favourites
- Personalized recommendations
- Community chat rebuild
- Admin or presenter management workflows

## Dependencies

- Final API/public endpoint availability.
- Final Figma mobile and desktop handoff.
- Font licensing/source.
- Ticketing, newsletter, analytics, and consent provider decisions.
